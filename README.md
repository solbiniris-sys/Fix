# WATERLINE FINAL — 생활형 수몰 도시 게임

기존 도시 탐험/저택 시스템을 유지하면서 플레이 루프를 `하루를 살아가기 → 도시/집 행동 → 생활 누적 → 자연 발생 사건 → 선택 → 다음 날 변화`로 확장한 최종판.

## 핵심
- 시간대/날짜/날씨
- 집 안의 실제 생활 행동
- 체력/허기/집/동물/관계
- 인벤토리와 도시 자원
- 시장/선착장/기록보관소/구주거구
- 생활 중 자연 발생하는 사건
- 사건 선택이 이후 상태와 아이템/단서에 영향
- 기존 도시 탐험 및 상태형 공간 시스템 보존
- 게임 화면 중심의 UI

## 실행
Railway에서 기존처럼 `npm install` 후 `node server.js`로 실행.

## 주의
이 작업 환경에는 express/socket.io가 설치되어 있지 않아 실제 Socket/browser boot는 로컬에서 주장하지 않았다. 아래 최종 검증은 Node syntax + 결정론적 전체 게임플레이 시뮬레이션으로 수행했다.
